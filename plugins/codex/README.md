# THRW for Codex

This package bundles the THRW remote MCP connection and one planning skill. It uses OAuth discovery; no credentials or local executables are bundled.

Install, authenticate, and update using the [Codex guide](https://github.com/ddppee/thrw-agent-plugin/blob/main/docs/codex.md). Preserve existing connections and avoid installing a second standalone copy of the skill. The skill's instructions cover confirmed actions, reuse of existing todos, and progress-stage checks while preserving existing content.

Verify tool access and skill discovery separately. Installation alone does not prove authentication or automatic skill selection. This GitHub package does not establish an official directory listing.
